# Home cards roadmap

TT Home cards should be standalone Torn-style `sortable-box` cards. They may use data from the currently loaded Home DOM, Torn API data, and TT local cache/history. Do not hidden-load or scrape non-API Torn pages that the user is not actively viewing.

Planned cards/status:

1. Effective Battle Stats — implemented
2. Battle Stat Growth — implemented
3. Training Planner — deferred; not implemented as a standalone card yet
4. Cooldowns & Timers — implemented
5. Networth Breakdown / Live Networth — implemented
6. Daily Checklist — implemented
7. Faction War / Chain Status — implemented
8. Travel Profit Finder — implemented
9. Crime Progress — implemented
10. Market Watchlist — implemented
11. Target / Enemy Shortlist — implemented
12. Loadout & Gear Quality — implemented
